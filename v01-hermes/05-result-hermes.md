# Agent 05 — Design Synthesis Result (Hermes)

## 苍南二期人事系统 — 设计综合概要

**设计主线**: 以"审批+考核+聘任"为核心的事件驱动人事管理系统，核心业务对象为"技术岗位聘任"，主要用户为人资和部门经理。

**产品结构策略**:
- primary_workspace: 统一待办中心（聚合跨模块任务）
- operation_center: 聘任工作台（组织规划管理员+培训工程师）
- object_detail: 考核详情页（徒弟/师傅/科长/部门经理）
- data_view: 人事大屏（管理决策支撑）
- supporting_module: 导师库/书库/档案管理

**体验策略**:
- 技术岗位聘任5种类型在同一页面切换（按晋升类型下拉）
- 评审会信息作为子表内嵌在聘任表单中
- 批量操作支持勾选+批量发起
- 退回操作标注原因必填+修改记录保留

**设计取舍**:
1. 审批链配置化 vs 硬编码 → 选择配置化（模板表），降低后续维护成本
2. 统一待办中心 → 推荐但待用户确认
3. 考核模板内置+可扩展 → 兼顾标准化和灵活性

**Writer表达策略**: 先讲用户工作场景(谁在什么情况下做什么)→再讲系统结构(服务/模块/页面)→功能追踪(按钮/状态/数据)
